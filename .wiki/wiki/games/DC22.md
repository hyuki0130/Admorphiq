## Observations

- Single-layer grid, movement game
- ACTION1-4 cardinal; ACTION6 can toggle barriers by clicking buttons
- `button_click_move`: click buttons first, then navigate the exit path

## Mechanics Hypothesis

Hybrid button + movement: certain buttons in the grid toggle barrier states; the player must click-toggle the right buttons and then walk to the exit.

## Lessons Learned

- Frame-only solver generalizes across version hashes. See linked lessons for why frame-observation strategies are preferred.
- [[../lessons/frame_diff_as_probe]]
- The current graph-search agent (`--agent unified`/`chained`) still clears
  0/6 here (R53, 2026-07-13) — the confining starting box the player begins
  in trips the SAME region-mask heuristic meant for HUD widgets (it responds
  to every movement key, same as a step counter would), blinding the graph
  to different in-box positions. Two candidate fixes were measured live and
  both falsified; see
  [[../lessons/dc22_confined_avatar_discriminator_falsified_20260713]]
  before re-attempting a discriminator for this.
- **script25 adapter built and live-probed (R56, 2026-07-15, commit
  `0e59f88`, `src/admorphiq/adapters25/dc22.py`).** A DIFFERENT agent
  family from the graph-search one above — identifies the avatar by direct
  movement measurement, never by the generic HUD/avatar region-mask
  discriminator, so it does not encounter the confining-starting-box
  failure at all. Reuses ka59's optimistic-passability navigation design;
  a measured seesaw button (opening one path while closing a different
  one) is handled by dropping any cell that changes after a probe click
  from `_known_blocked`, sidestepping the need to interpret button
  semantics. Live probe: 0/6, but avatar/goal identification, `dir_map`,
  and click-effect measurement are all individually verified correct — the
  wall is a probe-SEMANTICS gap (cosmetic indicator-flip cells
  over-counted as genuine barrier changes, plus a never-re-probe rule that
  incorrectly forbids the gold trace's genuine seesaw re-visit), not a
  plumbing gap. See [[../rounds/r56_generic-kernels]]'s "Measured so far
  (continued) — dc22" section for the full writeup.
